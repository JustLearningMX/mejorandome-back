# Contrato y Respuesta de Integración: Registro de Actividad Física (Pasos y Ejercicio)

- **Fecha:** 2026-10-28
- **Versión API:** v1
- **Prefijo base:** `/api/activity`
- **URL Base Local:** `http://localhost:3005/api`
- **Origen:** Backend NestJS (`mejorandome-back`)
- **Destino:** Frontend Astro (`mejorandome-front`)
- **Referencia:** `2026.10.28-activity-steps-exercise-endpoints-proposal.md`

---

## 1. Confirmación de Puntos de Decisión

1. **Ubicación y comportamiento de pasos (`steps`):**
   - El recuento de pasos se almacena en la entidad dedicada `DailyActivity` (`daily_activities`), la cual mantiene una relación 1:1 con el contenedor diario `HealthDay` (`healthDayId UNIQUE`).
   - El endpoint `POST /api/activity/steps` realiza un **Upsert atómico**: si ya existen pasos registrados para la fecha, actualiza el valor; de lo contrario, crea el registro.

2. **Meta diaria de pasos (`stepsGoal`):**
   - La meta se configura a nivel de usuario (`User.stepsGoal`, valor por defecto: `10000`).
   - Se expone el endpoint `PATCH /api/activity/goals` para personalizarla.
   - En las respuestas de pasos y del resumen se devolverán los campos calculados `goal` y `progressPct` (redondeado a un decimal, ej. `84.5`).

3. **Campos en sesiones de ejercicio (`ExerciseSession`):**
   - Aprobados los campos adicionales solicitados: `intensity` (`light`, `moderate`, `vigorous`, `extreme`) y `caloriesBurned` (opcional).
   - El campo temporal se estandariza como `occurredAt` tanto en peticiones como en respuestas (en lugar de `startedAt`) para mantener paridad con `MealEntry` y `WeightMeasurement`.
   - El catálogo propuesto (`walking`, `running`, `strength_training`, `cycling`, `swimming`, `yoga`, `hiit`, `sports`, `other`) queda plenamente admitido.

4. **Resumen de actividad (`GET /api/activity/summary`):**
   - Se implementará exactamente como fue propuesto, consolidando los totales del día actual y de los últimos 7 días.

5. **Código de respuesta en borrado de sesiones:**
   - `DELETE /api/activity/exercises/:id` devolverá `204 No Content` al eliminar exitosamente, alineado con el estándar REST y el módulo de nutrición.

## 2. Especificación de Endpoints

### 2.1 `POST /api/activity/steps` — Registrar o Actualizar Pasos del Día
Actualiza o crea el total acumulado de pasos para el día especificado (o el día de hoy por defecto según la zona horaria del usuario).

- **Método:** `POST`
- **Ruta:** `/api/activity/steps`
- **Autenticación requerida:** `Bearer <accessToken>`
- **Headers:** `Content-Type: application/json`

#### Body (JSON)
| Campo | Tipo | Requerido | Restricciones | Descripción |
|---|---|---|---|---|
| `steps` | `number` | **Sí** | Entero `>= 0`, máx `150,000` | Pasos acumulados del día. |
| `localDate` | `string` | No | Formato `YYYY-MM-DD` | Fecha del día. Si se omite, se usa la fecha actual local del usuario. |
| `occurredAt` | `string` | No | Formato ISO 8601 | Marca temporal del registro. |

```json
{
  "steps": 8450,
  "localDate": "2026-10-28"
}
```

#### Respuesta `200 OK` / `201 Created`
```json
{
  "id": "a1b2c3d4-e5f6-7890-abcd-1234567890ef",
  "localDate": "2026-10-28",
  "steps": 8450,
  "goal": 10000,
  "progressPct": 84.5,
  "updatedAt": "2026-10-28T20:15:00.000Z",
  "healthDay": {
    "id": "c1f2a3b4-5678-90ab-cdef-1234567890ab",
    "localDate": "2026-10-28"
  }
}
```

### 2.2 `GET /api/activity/steps` — Historial de Pasos Diarios
Consulta el historial de pasos para graficar tendencias y promedios.

- **Método:** `GET`
- **Ruta:** `/api/activity/steps`
- **Autenticación requerida:** `Bearer <accessToken>`

#### Query Params
| Parámetro | Tipo | Requerido | Default | Descripción |
|---|---|---|---|---|
| `startDate` | `string` | No | Hace 7 días | Fecha inicial (`YYYY-MM-DD`). |
| `endDate` | `string` | No | Hoy | Fecha final (`YYYY-MM-DD`). |
| `limit` | `number` | No | `30` | Límite máximo de días (`1` a `100`). |

#### Respuesta `200 OK`
```json
{
  "items": [
    {
      "localDate": "2026-10-28",
      "steps": 8450,
      "goal": 10000,
      "progressPct": 84.5,
      "completed": false
    },
    {
      "localDate": "2026-10-27",
      "steps": 10320,
      "goal": 10000,
      "progressPct": 103.2,
      "completed": true
    }
  ],
  "averageSteps": 9385,
  "totalSteps": 18770,
  "daysCount": 2
}
```

### 2.3 `POST /api/activity/exercises` — Registrar Sesión de Ejercicio
Registra una sesión de entrenamiento individual vinculada al `HealthDay`.

- **Método:** `POST`
- **Ruta:** `/api/activity/exercises`
- **Autenticación requerida:** `Bearer <accessToken>`

#### Body (JSON)
| Campo | Tipo | Requerido | Restricciones | Descripción |
|---|---|---|---|---|
| `exerciseType` | `string` | **Sí** | Catálogo: `walking`, `running`, `strength_training`, `cycling`, `swimming`, `yoga`, `hiit`, `sports`, `other` | Disciplina o tipo de ejercicio. |
| `durationMinutes` | `number` | **Sí** | Entero entre `1` y `720` | Duración en minutos. |
| `intensity` | `string` | No | `light`, `moderate`, `vigorous`, `extreme` | Nivel de intensidad percibida. |
| `occurredAt` | `string` | No | Formato ISO 8601 | Fecha y hora de la sesión (por defecto `now`). |
| `caloriesBurned` | `number` | No | Entero `>= 0` | Calorías estimadas. |
| `notes` | `string` | No | Máx 500 caracteres | Notas o descripción. |

```json
{
  "exerciseType": "strength_training",
  "durationMinutes": 45,
  "intensity": "moderate",
  "occurredAt": "2026-10-28T18:00:00.000Z",
  "caloriesBurned": 220,
  "notes": "Rutina torso superior y mancuernas"
}
```

#### Respuesta `201 Created`
```json
{
  "id": "e4b3c2a1-1234-5678-90ab-cdef12345678",
  "occurredAt": "2026-10-28T18:00:00.000Z",
  "exerciseType": "strength_training",
  "durationMinutes": 45,
  "intensity": "moderate",
  "caloriesBurned": 220,
  "notes": "Rutina torso superior y mancuernas",
  "createdAt": "2026-10-28T18:50:00.120Z",
  "healthDay": {
    "id": "c1f2a3b4-5678-90ab-cdef-1234567890ab",
    "localDate": "2026-10-28"
  }
}
```

- **Método:** `GET`
- **Ruta:** `/api/activity/exercises`

#### Query Params
| Parámetro | Tipo | Requerido | Default | Descripción |
|---|---|---|---|---|

| `localDate` | `string` | No | Ninguno | Filtrar por fecha local (`YYYY-MM-DD`). |
| `exerciseType` | `string` | No | Ninguno | Filtrar por tipo de ejercicio. |
| `startDate` | `string` | No | Ninguno | Rango inicial (`YYYY-MM-DD`). |
| `endDate` | `string` | No | Ninguno | Rango final (`YYYY-MM-DD`). |

#### Respuesta `200 OK`
```json
[

    "occurredAt": "2026-10-28T18:00:00.000Z",
    "exerciseType": "strength_training",
    "durationMinutes": 45,
    "intensity": "moderate",
    "caloriesBurned": 220,
```

### 2.5 `DELETE /api/activity/exercises/:id` — Eliminar Sesión de Ejercicio
Elimina una sesión de ejercicio existente perteneciente al usuario autenticado.

- **Método:** `DELETE`
- **Ruta:** `/api/activity/exercises/:id`
- **Autenticación requerida:** `Bearer <accessToken>`
- **Respuestas:**
  - `204 No Content`: Eliminada exitosamente (sin cuerpo).
  - `404 Not Found`: No encontrada o ajena al usuario.
